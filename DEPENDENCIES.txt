InFu 1.0.0 Source Build Notes
================================

This archive intentionally does not include node_modules, local configuration,
sessions, API keys, logs, screenshots, build output, or Git history.

Requirements
------------
- Windows 10 or later
- Node.js 22.5 or later
- npm (included with Node.js)
- Rust and the MSVC C++ Build Tools only when building the Windows native
  sandbox from source

Install dependencies
--------------------
1. Open PowerShell in the extracted InFu folder.
2. Run:

   npm install

The exact JavaScript dependency tree is pinned in package-lock.json.

Build and run from source
-------------------------
Run:

   npm run build
   npm run build -w @infu/web
   npm run start -w @infu/desktop

The desktop application uses the built Web assets in packages/web/dist.

Configure a model
-----------------
Run:

   npm run config

This creates local configuration in the current Windows user's ~/.infu
directory. API keys are not part of this archive and should never be committed
to a repository or uploaded with a backup.

Included bundled extensions
---------------------------
- browser-use
- control-browser
- web-gui-tester
- skill-creator

The archive does not include document-processing skills with restrictive
development-time licenses.

Verification
------------
After installing dependencies, run:

   npm test
   npm run build
   npm run build -w @infu/web
   npm run lint

Disaster recovery
-----------------
If the computer is lost or its data is erased, restore InFu in this order:

1. Download and extract this source archive to a writable folder.
2. Install the requirements listed above.
3. Run `npm install`, then the build and desktop commands in this document.
4. Run `npm run config` and enter model credentials again.
5. Open InFu and create or re-open project folders.

This source archive restores the application source, bundled extensions, and
build instructions. It intentionally cannot restore private sessions, model
keys, attachments, logs, recovery copies, schedules, or user-installed skills.

To restore those private items, maintain a separate encrypted backup of the
actual InFu data directory. The default location is `~/.infu`. If
`~/.infu-redirect.json` exists, read it first: it points to the active data
directory. Never upload an unencrypted copy of that directory because it can
contain API keys and private project material.

Recommended private backup set
------------------------------
- This clean source archive
- The portable ZIP and its SHA-256 file
- An encrypted archive of the active InFu data directory
- Optional: a `git bundle` backup of local Git history and unpushed branches

After extracting an encrypted data backup, restore it to the same Windows user
profile before starting InFu. If the original data directory was redirected,
restore both the data directory and `~/.infu-redirect.json`.
