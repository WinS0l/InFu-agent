# Windows 快速开始

这份说明面向第一次使用 InFu 的用户。你不需要懂 TypeScript、Rust 或命令行，也可以先使用便携版。

## 1. 下载与解压

打开项目的 GitHub Releases 页面，下载：

```text
InFu-1.0.1-win-x64-portable.zip
```

下载完成后：

1. 右键 ZIP 文件，选择“全部解压缩”。
2. 选择一个自己有写入权限的目录，例如：

   ```text
   D:\Apps\InFu
   ```

3. 不要只复制 `InFu.exe`。整个解压后的目录都必须保留，包括 `resources`、`locales` 和 DLL 文件。
4. 双击解压目录里的 `InFu.exe`。

## 2. Windows 安全提示

第一个公开版本没有商业代码签名证书。Windows Smart App Control 可能拦截未签名应用。

不要为了运行 InFu 关闭 Smart App Control、Defender 或其他系统保护。

如果 Windows 阻止启动，可以等待后续签名版本，或让熟悉开发环境的人按 README 中的源码方式运行。源码运行需要 Node.js、Rust 和 Windows C++ 构建工具。

## 3. 第一次启动

首次打开后，先进入“设置”，添加一个模型供应商。InFu 不提供模型额度，你需要使用自己的模型服务账号或本地模型。

常见选择：

- 已有 OpenAI、DeepSeek、Claude、Gemini、通义、智谱等服务账号：添加对应供应商并填写 API Key。
- 使用本地模型：安装并运行 Ollama，然后在供应商列表中添加 Ollama。
- 使用兼容 OpenAI API 的平台代理：添加自定义供应商，填写服务地址、模型名和 API Key。

API Key 保存在当前 Windows 用户的本地配置目录，不会上传到 GitHub，也不会写入项目文件。

## 4. 打开项目

在左侧点击“创建项目”或选择一个已有项目文件夹。建议从一个可以随时恢复的测试项目开始。

第一次给 InFu 的任务可以这样写：

```text
请先分析这个项目的技术栈、启动方式和测试入口。不要修改任何文件，最后用简短列表告诉我结论。
```

确认它能正确读取项目后，再尝试一个小任务：

```text
运行现有测试，找出一个失败项。先解释原因，再做最小修复，并运行相关测试验证。不要修改无关文件。
```

## 5. 使用建议

- 先让 InFu 分析和审查，再交给它修改代码。
- 第一次使用时，从小功能、测试修复或只读审查开始。
- 修改重要项目之前，确认当前项目已经使用 Git；InFu 可以创建工作树，便于审查、合并或丢弃改动。
- 模型可能出错。提交、部署、删除大量文件、修改生产配置前，请自己检查改动。
- “全权放行”会减少审批弹窗，但只应在你信任项目和任务内容时使用。

## 6. 数据在哪里

InFu 的个人数据保存在当前用户目录下的：

```text
~/.infu
```

其中包括模型配置、会话、日志、附件、恢复副本和本地索引。便携版目录可以移动或删除，但如果要完整清除个人数据，还需要处理这个目录。

应用内“设置”提供数据备份和数据目录迁移功能。建议在处理重要项目之前先创建一次备份。

## 7. 获得帮助

- 程序无法启动：确认没有只复制单独的 `InFu.exe`，应保留完整解压目录。
- 模型无法响应：检查 API Key、模型名称和供应商地址。
- 想报告问题：在 GitHub Issues 中附上任务描述、错误信息、InFu 版本、Windows 版本和可复现步骤。不要上传 API Key、会话数据库或私密项目文件。
